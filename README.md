# Mobile Device Software Development - Practical Works

This repository contains practical assignments for the university course on Mobile Device Software Development. The project is an Android application developed using Kotlin and the modern Android UI toolkit, Jetpack Compose.

The core theme of the application is an **Emergency Power Supply System**, which calculates, monitors, and displays various backup energy metrics.

## 🚀 Repository Structure

The application implements a tabbed navigation interface, where each tab corresponds to a specific practical assignment (PW). The source code and specific documentation for each practical work are located in their respective directories.

- **[PW#1](PW#1ТВ-31_Фельчин_Микола_Борисович/README.md):** Introduction to Jetpack Compose UI & State Management
- *PW#2, PW#3, PW#4 will be added as the course progresses.*

## 🛠️ Technologies & Tools
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose (Material Design 3)
- **IDE:** Android Studio
- **Build System:** Gradle (Kotlin DSL)

## ⚙️ How to Run
1. Clone this repository to your local machine.
2. Open the specific practical work folder (e.g., `PW#1ТВ-31_Фельчин_Микола_Борисович`) in **Android Studio**.
3. Allow Gradle to sync and download the required dependencies.
4. Build and run the application on an Android Emulator or a physical device.
